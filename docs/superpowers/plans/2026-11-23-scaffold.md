# План первоначального scaffold Aenea

Статус: выполнен. Это историческая запись о каркасе проекта; актуальные концептуальные решения находятся в [архитектуре](../../architecture.md).

**Цель:** подготовить воспроизводимый Python monorepo без подключения Telegram-аккаунта.

**Архитектура каркаса:** uv workspace содержит приложение Telegram и общий пакет contracts. RAID представлен конфигурацией сценария. Будущие приложения можно добавлять независимо.

**Стек каркаса:** Python 3.13, uv, Telethon, Ruff, GitHub Actions.
